After learning how Astro pages work, I decided I needed to add more posts. This post will show up on its own webpage, because Astro will create a page for every `.md` file inside the `src/pages/posts/` directory using the file name for the URL.

## What I'm learning

1. **Components**: I learned how to build reusable Astro components, like a `Navigation.astro` for my site's links.

2. **Layouts**: Astro layouts share common page elements, like headers and footers, across pages.

More to come as I continue!
